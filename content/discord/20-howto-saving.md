💾 **HOW TO: save in GTA VI (don't lose progress)**

• **Manual save:** Pause → **Game → Save Game**. Same menu to load.
• **Autosave is rare:** mostly after main missions and some bigger side missions, and each one overwrites the last.
• **You can't save** during a mission, a police chase, combat or while falling.
• **There's no "quit" option.** Save manually *before* closing the game from the console home screen.
