## How we make them
- Script: 1 host (or 2) written as sections, verified facts only, source on screen per claim.
- Voice: whole script in 1–2 Runway calls (host's fixed voice), then `tools/split_vo.py` cuts it into sentence lines.
- Video: `tools/podcast.py` 16:9 with B-roll behind every sentence: permitted gameplay (CC BY from Drive, credited) + official Rockstar shots/clips (unmodified, © Rockstar Games). `cast` = the speaking host(s) only, `label` = GUIDE / STORY / RANKED.
- Thumbnail: CC BY gameplay frame + host + 3–4 words (never text on Rockstar images).
- YouTube: chapters in the description (from the line timeline), sources, CC BY credits, "AI-voiced character" note. Long videos get priority in the 4 uploads/day.
